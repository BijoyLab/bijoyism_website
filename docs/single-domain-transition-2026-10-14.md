# 暂行单域名访问方案

2026-10-14 用户确认，在 `.cn` 备案、托管和 HTTPS 尚未就绪期间：中国用户默认访问 `https://bijoyism.cc/zh/`，海外用户默认访问 `https://bijoyism.cc/en/`。联系邮箱为 `support@bijoyism.cn`。

## 本地修改

- `site-config.js` 两种语言的公开 origin 都指向 `.cc`。中文 canonical、hreflang、JSON-LD 产品/Article 地址、公司 sameAs、图片地址、语言切换和页脚语言链接同步使用 `.cc/zh/`。
- 生产根路径保留地区识别和已有语言偏好，只会跳到 `.cc/en/` 或 `.cc/zh/`。中国默认中文，海外默认英文；手动选择语言优先。显式语言路径不被地区强制覆盖。
- `.cc/sitemap.xml` 同时包含两种语言的规范页面，排除历史别名。robots 的 Sitemap 地址固定为 `.cc/sitemap.xml`，继续允许搜索抓取。
- 如未来 `.cn` 请求已能到达本应用，则提供临时 307 至 `.cc` 的兼容跳转；这段代码不解决 `.cn` 的 TLS 握手问题，也没有修改腾讯云 DNS 或邮箱记录。
- 更新结构化数据、Sitemap 和地区跳转回归断言，防止未就绪的 `.cn` 地址重新进入对外页面。

## 发布后验收

1. 无语言偏好时，中国根路径请求到 `.cc/zh/`，海外到 `.cc/en/`；已有语言选择保留。
2. 中英文 About 与三个产品页的 canonical 都使用 `.cc`，只通过语言路径区分；HTML 不再出现 `https://bijoyism.cn` 网站入口。
3. 两个方向的语言切换均在 `.cc` 内，保留路径、查询参数和锚点。
4. Sitemap 含英文、中文规范页面，不出现 `.cn` 网站 URL；robots 仍放行 OAI-SearchBot。
5. `support@bijoyism.cn` 原样保留。

未来 `.cn` 正式可用后再统一调整规范域名、语言关联、Sitemap、跳转和测试。原双域名实施/巡检文档保留为历史记录，本文件是当前域名方案。

此次没有生产发布配置或发布脚本可直接调用；本地构建须通过原部署流程发布后，线上访问策略才会改变。

验证结果：代码检查通过，19 项单元测试全部通过，生产构建通过，3 项 GEO HTTP 回归通过。实际验证了中国默认 `.cc/zh/`、美国默认 `.cc/en/`、已有英文偏好优先、中文 canonical 和检测关联地址使用 `.cc`，以及 Sitemap 同时包含两种语言且没有 `.cn` 地址。
