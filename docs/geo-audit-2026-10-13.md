2026-10-13 事实更正：用户确认 TD01、TD02、TD03 一起检测，并在同一份证书上列明。撤回此前仅凭 TD01 样品照片认定 TD02/TD03 未被覆盖的判断。三个当前系列的检测覆盖已确认；后续工作是展示准确的型号、文件和适用项目，避免泛化至未来产品或未测试性能。

## 最重要的三项工作

### 1. 把正确版本发布到生产并验收抓取

部署包含当前公司事实、声明修正、允许抓取和 Sitemap 清理的构建。上线后直接核验 `/robots.txt`、英文/中文首页、About 和三个产品详情页，确保没有 noindex 或 X-Robots-Tag 索引限制。检查真实生产防火墙/爬虫日志，避免仅放行普通浏览器。

验收：公开核心页 200；robots 允许目标搜索爬虫；页面可索引；About HTML 与 Organization 包含同一套主体事实；Sitemap 不含历史重定向地址。允许索引不等于保证收录或引用。

### 2. 建立型号事实与公开证据对应关系

公司信息放 About；三个系列的规格、材料、年龄和使用条件放各自产品页；检测证据按型号列出，不放成全站泛化安全承诺。

当前产品真相源记录报告 C202602050363E、CPC CPCC202602050363E（2026-04-02）及毒理评估 DJ2603180401（2026-03-25）。用户已确认 TD01、TD02、TD03 共同检测，并在同一份证书列明；本次未重新独立复核原件。公开摘要应列出三型号及文件适用项目。该确认不自动确定单独毒理评估或 GB 6675 的范围。

公司事实 MD 仍可维护为底稿，公开 HTML 与 JSON-LD 应从同一事实层生成。每个产品事实记录 source、verified date、model applicability；内部文件路径不必暴露给网站访客。

验收：HTML 与 JSON-LD 一致；SKU、型号、ASIN 各有明确用途；不出现无依据的防滑、全系列通过测试或疗效；内部事实引用不再指向迁移前根目录 `product-truth.md`，应指向当前 `Product/03-truth/product-truth.md`。

### 3. 建立从用户问题到 Amazon 销售的测量闭环

优先完善品类选择、三系列比较、清洁和儿童室内游戏问题。每页自然关联适用产品，再连接对应 Amazon 落地。符合资格时配置 Attribution，并将现有 purchase-click 事件接到可用的统计系统。

验收：能按语言、来源、问题簇、系列和 CTA 位置查看点击；Amazon 归因报表能够对应已配置链接；引用、访问、点击、购买分别记录，不互相替代。

## 技术细节与低优先级注意事项

- `www.bijoyism.cc/en/` 与非 www 均返回内容，canonical 指向非 www；canonical 已提供规范信号，统一 301 可减少重复入口。
- 页面 HTTP Link 的语言标记与 HTML metadata 应统一；地区/语言重定向保留人工切换与爬虫可达性，不因地区硬跳转隐藏内容。
- Animal Safari 原始 HTML 同时包含打印卡和屏幕内容，提取文本出现重复；检查打印样式和语义区分，不将其认定为处罚或引用失败原因。
- Article 可补真实审核日期和代表图片；Breadcrumb 应对应实际导航层级。JSON-LD 的 WebPage 可用 mainEntity/about 关联 Product/Organization，但这些字段不保证 AI 引用。
- Offer、评分、评价只在真实有效且页面可见时标注；Amazon 外链站不必伪装为官网直接售卖。
- Sitemap lastmod 仅在能跟踪真实实质更新时添加，不每日刷新所有 URL。
- 不优先新增 llms.txt 或公开 MD。Google 明确不需要特殊 AI 文本文件、全站问句标题或特定段落长度；可靠内容与正常搜索基础更重要。
