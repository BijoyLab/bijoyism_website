## 1. 目标与页面分工

让玩法页负责“具体怎么玩”，家庭页负责“如何陪伴、如何融入日常”，学校页负责“如何组织课堂活动”。统一玩法数据与入口，避免同样的卡片和介绍在各页反复出现。中英文内容分别写作，含义与事实一致，中文不照搬英文结构。

| 页面 | 内容职责 | 玩法展示与入口 |
| --- | --- | --- |
| 首页 | 介绍品牌、产品及游戏体验 | 去掉四种方式模块，保留 3–4 个精选玩法与查看全部玩法入口 |
| 玩法页 | 查找具体玩法 | 14 种玩法统一展示为独立卡片，通过筛选寻找 |

| 家庭页 | 亲子陪伴与日常游戏理念 | 不展示玩法卡片；单一主要入口进入家庭场景的玩法列表 |

## 2. 玩法页结构

页面顺序：简短标题与介绍 → 筛选区 → 结果数量与已选条件 → 独立玩法卡片 → 家长／教师活动组织指南。

删除四种方式大模块、按系列划分的大背景区域、区域内产品介绍及重复购买入口。保留 14 种玩法（12 个主要玩法、2 个简单玩法）；2 篇组织指南独立展示，不计入玩法数量、不混入筛选结果。

### 筛选

- 产品系列：全部系列、动物探索、缤纷双色、水漾色彩、多系列组合。
- 年龄、参与人数、使用场景沿用经核实的玩法数据；不改变玩法年龄或适用条件。
- 所有条件共同生效；修改选项立即更新结果，移除“应用”按钮。
- 显示“找到 X 种玩法”、当前条件及“清除筛选”；无结果时解释如何放宽条件。
- 单系列选项仅列出该系列即可完成的玩法；组合玩法归入“多系列组合”，明确所需系列及套数，不能暗示单套可完成。
- 筛选写入 URL，例如 `?collection=td01&setting=home`。具体参数在实施时与现有过滤规则统一；旧链接仍可访问。
- 通过数据登记扩展系列，不把 TD01–TD03 写死在筛选组件中。

### 卡片

统一包含动作图标、名称、一句玩法介绍、所需系列、年龄与人数、查看玩法入口。简单玩法有清晰标签；组合玩法注明所需产品。卡片不嵌入系列背景容器。

桌面三列、平板两列、手机一列；桌面内边距 24px，平板／手机 20px，卡片间距至少 16px。不同语言、长标题下都要确保文字不贴边、不溢出。

## 3. 家庭页内容方案

主标题：**一起玩，让日常多一点发现。**

介绍：不必安排复杂的活动。从看看颜色、轻轻按一按，到一起排出路线，让孩子顺着自己的兴趣探索，也让陪伴自然发生。

三个模块，采用场景图配文字的形式，不展示玩法卡片：

1. **让孩子自己发现怎么玩**  
   孩子可以先看看颜色、摸摸表面，再试着踩一踩、排一排。给他们一点时间，让玩法从好奇心中慢慢出现。
2. **一起发现，不用安排每一步**  
   家长可以问一句“你看到了什么？”，也可以跟着孩子试一试。路线怎么排、故事怎么讲，让孩子也来做决定。
3. **留一小块空间，随时一起玩**  
   在客厅或游戏角留出合适的空间。想动一动时试着排路线，想慢下来时一起观察颜色变化，根据当天的兴趣选择玩法。

主要按钮：**查看家庭玩法** → 玩法列表的家庭场景结果。正文与入口之间保留当前产品经确认的使用条件，不能因简化页面而移除必要说明。

英文围绕陪伴、孩子自主探索、日常空间分别表达；不逐句翻译上述中文。

## 4. 学校页内容方案

主标题：**让色彩和动作，融入课堂活动。**

介绍：从观察颜色到轮流参与，再到一起设计路线，教师可以根据人数、空间和活动安排，选择适合班级的游戏方式。

三个模块，采用课堂场景与组织说明，不展示玩法卡片：

1. **同一个主题，让孩子用不同方式参与**  
   围绕颜色、动物或路线开展活动。有的孩子先观察，有的说说自己的发现，也可以通过动作参与，让活动有不同的参与方式。
2. **把轮流和合作放进具体的游戏里**  
   提前说明从哪里开始、什么时候轮到下一人、如何一起完成。让孩子在具体活动中理解顺序、交流想法。
3. **按班级情况，灵活安排活动**  
   根据参与人数、空间大小和活动节奏，安排小组探索、轮流体验或安静观察。规则先从简单开始，再按实际情况调整。

主要按钮：**查看课堂玩法** → 课堂场景筛选结果。机构定制作为独立次要模块，保留已确认事实：三款均可定制图案与颜色、可提供机构图稿／Logo、最低 5 套、可先打样、费用按需求确定。联系与购买路径沿用现有配置。

英文围绕多种参与方式、活动轮换、小组安排表达；不暗示治疗或保证学习效果。

## 5. 中文表达原则与统一用词

本次调整涉及的页面和共用文案均做中文通读，不仅替换一个标题。玩法详情与打印内容同步检查，防止页面与打印措辞不同。

| 需调整的表达 | 推荐中文 |
| --- | --- |
| 一个邀请，多种参与方式 | 同一个主题，让孩子用不同方式参与 |
| 游戏邀请／开放的游戏邀请 | 按语境使用“玩法”“游戏活动”“一起试试”；不用作反复出现的固定术语 |
| 找到适合你们的游戏邀请 | 找到适合一起玩的方式 |
| 自创冒险 | 自己设计游戏路线（描述路线活动时） |
| Aqua = 停顿／Pause | 想慢下来时，看看颜色的变化；使用正式产品名“水漾色彩” |
| Signature／Starter | 按功能使用“推荐玩法”“简单玩法”，不生硬翻译“签名玩法” |
| 空间／场景筛选 | 使用场景 |
| 人数筛选 | 参与人数 |

先保留既有玩法名与稳定 ID，对不自然的名称在逐项核对实际步骤后改写。标题讲明要做什么，正文提供具体动作和场景；避免抽象口号、英文隐喻直译和没有事实依据的效果承诺。品牌 slogan“唤醒感知，启迪心智”保持已确认版本。

事实清单：不调整产品规格、每套数量、年龄条件、使用与安全说明；不增加认证、治疗、智力或学习结果保证。中文 cm／英文 in 规则沿用当前网站要求。

## 6. 全站关联与交互要求

- 搜索所有玩法引用、四种方式区块和系列锚点，建立入口对照清单。
- 既有玩法详情 URL 和 ID 保持稳定，外部链接与收藏继续有效。
- 产品页“更多玩法”进入该系列结果；家庭／学校按钮分别带场景条件。
- 首页精选推荐独立于列表排序，使用稳定 ID；不因排序变化而推荐错误内容。
- 所需系列标签由产品数据生成，不另写一份产品名称。
- 从列表进入详情后，返回时恢复筛选与滚动位置；浏览器前进后退与切换语言保持筛选一致。
- 新的筛选 URL 优先于旧的返回记录，避免从家庭／产品页进入时被上次浏览状态覆盖。
- 所有新事件随组件卸载清理；每次语言选择只发起一次导航。
- 打印继续展示完整玩法内容和使用提示；屏幕布局调整不破坏现有打印布局。
